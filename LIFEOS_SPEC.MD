# LifeOS

## Vision

LifeOS is a personal life-management web application that helps people
remember and manage important everyday responsibilities from one place.

## Core Promise

"Never forget what matters."

## Target Users

- Students
- Working professionals
- Parents
- Freelancers
- Families
- General users

## Core Features

### Dashboard
Show:
- Today's important items
- Upcoming deadlines
- Overdue items
- Upcoming bills
- Subscription renewals
- Document expirations
- Warranty expirations
- Quick Add button

### Reminders
Users can create:
- One-time reminders
- Daily reminders
- Weekly reminders
- Monthly reminders
- Yearly reminders
- Custom recurring reminders

### Bills
Track:
- Electricity
- Water
- Internet
- Mobile
- Rent
- EMI
- Insurance
- College fees
- Other payments

### Subscriptions
Track:
- Service name
- Price
- Billing cycle
- Next renewal date

Show monthly and yearly subscription cost.

### Documents
Track:
- Passport
- Driving licence
- Vehicle registration
- Insurance
- Certificates
- Academic documents
- Other documents

### Warranties
Track:
- Product
- Purchase date
- Price
- Warranty period
- Warranty expiry
- Return deadline

### Calendar
Display all important LifeOS events.

### Search
Search across reminders, bills, subscriptions,
documents and warranties.

## Design

LifeOS should feel:
- Modern
- Premium
- Minimal
- Trustworthy
- Extremely easy to use

Use:
- Clean typography
- Rounded cards
- Good spacing
- Subtle animations
- Responsive design
- Light and dark mode

## Technology

Frontend:
- React
- TypeScript
- Vite
- Tailwind CSS

Backend:
- Node.js when required

Database:
- Supabase PostgreSQL

Authentication:
- Supabase Auth

Deployment:
- Vercel

## Development Rules

1. Keep components modular.
2. Use TypeScript properly.
3. Don't rewrite working code unnecessarily.
4. Don't add unnecessary dependencies.
5. Keep business logic separate from UI.
6. Validate user input.
7. Never expose secret API keys.
8. Use environment variables.
9. Make the application responsive.
10. Build and test features one at a time.
